# Tool allow-list for the headless kulturni-prehled runs (weekly + sezona).
# session_settings.py puts it into the session's --settings file
# (permissions.allow), {REPO} filled in. Deliberately absent: git push, gh,
# any email connector — the only send path is the KP API itself.
#
# Enforced with --permission-mode dontAsk since 2026-09-30, and since
# 2026-10-10 the session is --restricted (the box's user settings are not
# loaded; this list no longer only adds to them) and its Bash runs in the
# Claude Code sandbox (bubblewrap): writes only to the checkout and /tmp, no
# reads of denied-tools.txt's places, network only to sandbox-domains.txt,
# no unsandboxed retry. That is why `Bash` can stay whole: the runs are built
# on multi-line python heredocs, jq pipelines and $(...), which no command
# list can express, and the sandbox — not this list — bounds what they reach.
# ToolSearch: loads deferred tools (WebFetch and friends); dontAsk denies it
# unless listed, and the runs use it every week.

# own data — lib.sh parks such edits as a patch + stash and alerts) and the
# work dirs under /tmp. Edit rules govern the Write tool too.
